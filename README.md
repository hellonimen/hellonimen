### 🔭 What I work on

I'm interested in where **web application security meets LLM security**: the new attack surface that appears when you bolt a language model onto a normal web app.

My **final-year project** builds a deliberately vulnerable AI chatbot and a black-box scanner that shows how an **LLM-layer flaw can drive a web-layer exploit**, across the layer boundary that most scanners never cross. It detects six vulnerabilities (SQLi, IDOR, Stored XSS, Prompt Injection, System Prompt Leakage, Insecure Output Handling) and reconstructs two cross-layer attack chains, mapped to the OWASP Top 10 (2021) and the OWASP Top 10 for LLM Applications (2025). It ships with 102 automated tests and a GitHub Actions security gate that fails a build on any finding.
